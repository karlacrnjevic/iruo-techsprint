# IRUO TechSprint

Projekt iz kolegija Implementacija računarstva u oblaku.

Cilj projekta je automatizirana implementacija izoliranih testnih okolina za Moodle aplikaciju koristeći Microsoft Azure i OpenStack.

## Tehnologije

- Terraform
- Ansible
- Microsoft Azure
- OpenStack
- Git
- GitHub
